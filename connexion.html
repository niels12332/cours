Vérifier mon email ↗

Signal privé

Une adresse. Un code. Pas de mot de passe.

Cette vérification permet de confirmer ton adresse pour recevoir les nouvelles du laboratoire. Le code expire après dix minutes.

01

Recevoir le code

Entre ton adresse. Un code à six chiffres sera envoyé si le serveur SMTP est configuré.

02

Confirmer l’adresse

Recopie le code reçu. Tu n’as pas besoin de ressaisir ton email.

À savoir

Les ressources restent publiques. Cette étape sert uniquement à confirmer ton adresse et à préparer les échanges par email.
